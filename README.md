# AirLink

Программа для быстрой передачи файлов между компьютером и телефоном по локальной сети Wi-Fi. Работает напрямую без проводов, интернета и сторонних облачных сервисов.

## Как это устроено

Проект состоит из двух частей: десктопного приложения и мобильного веб-интерфейса.

* **Десктоп (ПК):** Интерфейс написан на PyQt6. В фоновом потоке запускается локальный сервер на FastAPI (Uvicorn), благодаря чему при передаче больших файлов окно программы не зависает.
* **Телефон:** Устанавливать отдельное приложение на телефон не нужно. При запуске на ПК программа генерирует QR-код с локальным IP-адресом. При сканировании камерой в браузере смартфона открывается простая веб-страница (HTML/JS), через которую можно отправлять и скачивать файлы.
* **Передача данных:** Идет напрямую через локальный HTTP-сервер потоками, не перегружая оперативную память.

## Стек технологий

* Python 3
* PyQt6 — интерфейс для ПК
* FastAPI / Uvicorn — локальный веб-сервер
* qrcode, Pillow — генерация QR-кода сопряжения
* HTML / JS / CSS — веб-интерфейс для телефона
* PyInstaller — сборка в standalone .exe
