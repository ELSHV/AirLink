AirLink:

Десктопное приложение для прямой передачи файлов между компьютером и мобильными устройствами по локальной сети Wi-Fi. Программа работает напрямую без интернета, проводов и облачных сервисов.

О ПРОЕКТЕ:

AirLink решает задачу быстрого обмена файлами между ПК и смартфонами внутри домашней или рабочей сети. Вместо пересылки файлов через мессенджеры, использования внешних облаков или подключения проводов программа поднимает локальный сервер на компьютере. Сопряжение происходит мгновенно: камера телефона сканирует QR-код на экране, после чего в браузере смартфона сразу открывается панель управления.

ОСНОВНЫЕ ФУНКЦИИ:

* Работа без установки приложений на телефон. Смартфон выступает тонким клиентом через обычный браузер.
* Двусторонняя передача. Поддерживается отправка файлов с телефона на ПК и обратно с компьютера на телефон через область перетаскивания файлов Drag and Drop.
* Высокая скорость и приватность. Передача данных идет на максимальной скорости локального роутера без выхода во внешнюю сеть.
* Фоновый сервер. Передача тяжелых файлов не блокирует интерфейс десктопного приложения.
* Мониторинг подключений. На вкладке устройств фиксируются текущие сессии с отображением IP адреса и типа устройства.

АРХИТЕКТУРА ПРИЛОЖЕНИЯ:

Приложение построено по клиент-серверной модели, где компьютер является хостом, а смартфон клиентом.

1. Многопоточность. В основном потоке работает графический интерфейс на PyQt6, который обрабатывает действия пользователя, анимации и события перетаскивания файлов. В фоновом потоке в режиме демона запущен сервер FastAPI под управлением Uvicorn. За счет изоляции потоков отправка больших файлов не приводит к зависанию окна программы.
2. Сетевое сопряжение. При запуске утилита определяет локальный IPv4 адрес компьютера в текущей подсети через системные сокеты. На базе этого адреса библиотека qrcode генерирует матрицу кода, которая отображается в окне программы. При наведении камеры смартфона ссылка открывается в мобильном браузере без ручного ввода адресов и паролей.
3. Потоковая передача. Файлы передаются потоком через multipart запросы фиксированными частями прямо на диск компьютера, что исключает переполнение оперативной памяти.
4. Мобильный клиент. Веб-страница написана на чистом HTML, CSS и JavaScript без тяжелых внешних библиотек, благодаря чему интерфейс загружается на телефоне мгновенно.

ТЕХ-СТЕК:

* Язык программирования: Python 3
* Десктопный интерфейс: PyQt6
* Локальный сервер: FastAPI и Uvicorn
* Сеть и графика: socket, qrcode, Pillow
* Мобильный интерфейс: HTML5, CSS3, JavaScript
* Упаковка: PyInstaller

СТРУКТУРА ФАЙЛОВ ПРОЕКТА:
AirLink

- main.py: точка входа, запуск графического интерфейса и фонового потока сервера
- server.py: эндпоинты FastAPI для приема, отдачи файлов и учета подключенных устройств
- utils.py: функции определения локального IP адреса и путей к файлам
- requirements.txt: список зависимостей проекта
- ui main_window.py: логика главного окна PyQt6 и область Drag and Drop
- ui styles.py: стили оформления интерфейса
- ui icon.ico: иконка приложения
- ui templates mobile.html: веб-страница для мобильного браузера

УСТАНОВКА И ЗАПУСК:

1. Склонировать репозиторий:
git clone [https://github.com/ELSHV/AirLink.git]
cd AirLink
2. Создать и активировать виртуальное окружение:
python -m venv venv
venv\Scripts\activate
3. Установить зависимости:
pip install -r requirements.txt
4. Запустить программу:
python main.py

СБОРКА В ИСПОЛНЯЕМЫЙ ФАЙЛ:

Для сборки проекта в один exe файл используется команда:
pyinstaller --noconsole --onefile --icon=ui/icon.ico --add-data "ui;ui" main.py

Готовый файл появится в папке dist.
